The official Go implementation of Google Genkit (maintained within the `genkit-ai/genkit` repository under `go/` and imported as `github.com/firebase/genkit/go`). Brings Genkit's model abstraction, prompt management, tool calling, and OpenTelemetry instrumentation to high-performance Go services and cloud functions.
