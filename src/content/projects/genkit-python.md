The official Python implementation of Google Genkit (maintained within the `genkit-ai/genkit` repository under `py/` and distributed via PyPI as `genkit`). Enables Python developers to build production-grade agentic workflows, orchestrate flows, validate structured outputs with Pydantic, and inspect traces using the local developer UI.
